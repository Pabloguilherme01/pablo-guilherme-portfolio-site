# Pablo Guilherme Portfolio — artefato publicado

> **Repositório gerado. Não editar o site manualmente aqui.**

Este repositório contém o build estático publicado do portfólio. O código-fonte é mantido separadamente em `Pabloguilherme01/pablo-guilherme-portfolio`.

## Regra de publicação

Uma atualização deste repositório deve ser gerada a partir de um commit conhecido do repositório-fonte. O commit de publicação deve registrar no texto da mensagem o SHA de origem sempre que o processo de deploy permitir.

Arquivos como `index.html` e `assets/` são artefatos de build e não são a fonte de verdade para desenvolvimento.

## Correções

Corrija componentes, conteúdo e estilos no repositório-fonte e gere uma nova publicação. Evite patches manuais diretamente no HTML compilado.

## Publicação automatizada

O repositório-fonte possui um workflow de publicação cross-repo. Publicações automáticas gravam o SHA de origem em `SOURCE_COMMIT`. Consulte [PUBLISHING.md](PUBLISHING.md) para o contrato de proveniência e recuperação.
